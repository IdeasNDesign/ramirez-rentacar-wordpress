# Ramirez PayPal Booking Gateway

Plugin profesional de integración de pasarela de pago PayPal (Orders API V2) para el sistema de reservas de **Ramírez Rent A Car**.

## Características
- Conectividad segura a Sandbox y Live.
- Cálculo de depósito del 10% del total de alquiler en servidor en centavos.
- Idempotencia y bloqueos de concurrencia integrados.
- Registro completo de auditoría y webhooks verificados.
- Wizard de instalación en 5 pasos.
